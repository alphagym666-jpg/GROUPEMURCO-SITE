SITE GROUPE MURCO — groupemurco.com
===================================

METTRE EN LIGNE
Recommandé : relier Netlify au dépôt GitHub « groupemurco-site »
(Netlify → ton projet → Project configuration → Build & deploy →
Link repository). Ensuite, chaque modification poussée sur la branche
principale est publiée toute seule. Aucune commande de build : laisse
« Build command » et « Publish directory » vides.

Sinon, à la main :
1. app.netlify.com → ton projet → onglet Deploys.
2. Glisse CE DOSSIER au complet dans la zone "Drag and drop".
3. Attends "Published".

FORMULAIRES
Onglet Forms → active la détection si besoin, puis ajoute une
notification courriel vers info@groupemurco.com.
Dans chaque demande, le champ « services-choisis » liste TOUS les
services cochés par le client.

VOS PHOTOS
Voir photos/LISEZ-MOI.txt : dépose tes photos dans le dossier photos/
avec les bons noms, elles remplacent les illustrations toutes seules.

AVIS CLIENTS
assets/avis.js — ajoute les vrais avis dans la liste AVIS, et colle
le lien de ta fiche Google dans LIEN_AVIS_GOOGLE.

GOOGLE
La balise de vérification Search Console est déjà sur toutes les pages.
Après chaque mise en ligne importante, va dans Search Console et
demande l'indexation de la page modifiée.

IMAGE DE PARTAGE
assets/partage.jpg (1200 x 630) s'affiche quand quelqu'un partage le
site sur Facebook, Messenger ou par texto.

POLICES
Les polices (Anton, Archivo) sont dans assets/fonts : le site ne
contacte plus Google Fonts.

PRIX « À PARTIR DE » (À CONFIRMER AVANT LA MISE EN LIGNE)
Gouttières 200 $, protège-gouttières 650 $, lavage à pression 250 $,
vitres 150 $, feuilles 175 $. Ils sont écrits dans index.html,
services.html, les 6 pages de villes (cartes « Dès … $ ») et dans
la bannière de l'accueil (« Gouttières dès 200 $ »).

MAQUETTE : IMAGES DE BANQUE À REMPLACER AVANT LA VRAIE MISE EN LIGNE
Tout ce qui est dans photos/maquette/ vient de Pexels (licence gratuite,
usage commercial permis). Ce ne sont PAS des jobs de Groupe Murco :
- hero-video(-mobile) : accueil. Plans : jet de pression sur béton, laveur
  de vitres à la perche, travailleur en hauteur, feuilles d'érable.
  → Refaire : toi dans l'échelle, gouttière vidée, jet sur un revêtement.
- svc-lavage-pression, svc-lavage-vitres, svc-feuilles : page Services.
  → Refaire : même cadrage, avec ton équipement.
- entete-*.jpg : en-têtes des pages (Services, À propos, Contact, Avis,
  pages de villes). bande-maison-*.jpg : bandeaux de l'accueil.
  → Remplacer par des photos de maisons que tu as faites (après la job).
Sources Pexels — vidéos : 6160418, 6196264, 2675565, 3105317 ;
photos : 5652625, 5652626, 6422928, 6422929, 18093637.

CONFIGURATION (assets/config.js)
- PRIX : taux du calculateur de prix (page Services). À CONFIRMER.
- NUMERO_RBQ, ASSURANCE : remplis-les et les badges apparaissent sur
  l'accueil. Laisse "" sinon.
- GOOGLE_ANALYTICS_ID, META_PIXEL_ID : remplis-les avant tes pubs. Une
  bannière de consentement (Loi 25) s'affiche alors automatiquement.

GARANTIE 30 JOURS
Affichée sur l'accueil et la page Services. Assure-toi de pouvoir
l'honorer avant la mise en ligne, ou modifie le texte.
